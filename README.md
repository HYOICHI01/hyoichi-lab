# HYOICHI Lab
HTML / CSS / Vanilla JavaScriptによるレスポンシブ対応の静的サイトです。
AFK HEROの開発プロジェクトとは独立しています。ビルドやnpm installは不要です。

## PCで確認
1. index.htmlをChromeやEdgeで開きます（ダブルクリック、またはブラウザへドラッグ）。
2. ウィンドウ幅1280〜1440px、ズーム100%を目安に確認してください。
3. 上部ナビゲーションでGAME / PRODUCTS / CREATOR / NEWS / CONTACTへ移動できます。
Google Fontsのみインターネット接続を使用します。オフライン時はsans-serifに切り替わります。
PC版デザインは確認・確定済み。これを基準にスマートフォン・タブレット対応を追加しています。
768px以下は1カラムとハンバーガーメニュー、769〜1039pxは横型ナビを保った小型PC向け補正です。

## ファイルと更新箇所
- docs/SPEC.md：Ver.0.3の正式仕様と2026-09-20の補足仕様。
- index.html：紹介、SNS、作成中ゲーム、最新NEWS、CREATOR紹介、CONTACT導線。
- game.html：サイト上で直接遊べるWebブラウザゲーム専用。
- products.html：Android / iOS / Steam等で公開・販売するゲーム・アプリ。個別詳細ページはまだ作成しません。
- creator.html：プロフィール、活動、SNS。
- news.html：お知らせ。現状はサンプル。実データでは年別見出しを作り、新しい順に追記します。
- contact.html：入力UIのみ。送信・同意は無効。送信先メールアドレスはありません。
- css/style.css：色、共通部品、ページ別スタイル。ブランドカラーは先頭の変数で管理。
- js/main.js：メニュー開閉・キーボード対応・画面幅切替とフォーム送信の抑止。入力値の通信や保存は行いません。
- images/common/favicon.svg：暫定のHアイコン。

### 共通部分
ヘッダー・フッターは6つのHTMLに直接記述しています。変更時は全ページへ反映してください。
現在ページのaria-current="page"はページごとに保持してください。

### 立ち絵・ゲーム画像
images/creator/、images/games/に配置します。各フォルダのREADMEも参照してください。
立ち絵はimages/creator/hyoichi.pngを使用しています。ゲーム画像のプレースホルダーはHTML/CSSによる仮表示で、実際のゲーム画面ではありません。

### SNS
index.htmlとcreator.htmlの.social-listを編集します。
URL確定後、各.social-itemをspanからaへ変更し、実URLをhrefに設定してください。
別タブで開くならtarget="_blank"とrel="noopener noreferrer"、外部リンク表示・読み上げラベルも追加します。

### ゲーム
index.htmlの.game-cardが作成中ゲームの例です。Web / Android・iOS / Steam・PCなどプラットフォームを問わず掲載します。
外部プラットフォーム向け作品はproducts.htmlへカードを追加し、確定した対応先やストアリンクを記載します。ゲーム以外のアプリ等にも同じカード構造を利用できます。未確定のストアURLはリンクにしません。初期カードは掲載サンプルです。
Webゲームはgames/配下に本体を置き、game.htmlのコメントに従ってPLAYリンクを有効化します。
未公開ゲーム用の偽のリンクや個別詳細ページは作成していません。

### NEWS
TOPは最新3〜5件、news.htmlは過去記事も残して管理します。両方のHTMLを更新してください。
サンプルは実際の公開実績ではありません。公開前に実データへ差し替えるか削除してください。
実日付は <time datetime="2026-09-20">2026.09.20</time> のように記述します。

## レスポンシブ確認
ブラウザの開発者ツールで1440 / 1024 / 768 / 430 / 390 / 375pxに切り替え、6ページを確認します。
- 横スクロール、文字・画像の見切れ、立ち絵とクレジットの重なりがないこと。
- 768px以下でメニューを開閉し、Tab / Enter / Space / Escapeで操作できること。
- 項目選択・外側クリックで閉じ、PC幅へ戻すと横型ナビになること。
- 固定ヘッダー、縦向き・横向きの低い画面、フォーム入力欄も確認すること。
- CONTACTは送信不可。同意チェックと送信ボタンは引き続き無効です。
ローカルファイルURLはこの作業環境のブラウザ操作ポリシーで拒否されており、
エージェントによる実ブラウザ表示確認は未実施です。コード検証とは区別してください。
